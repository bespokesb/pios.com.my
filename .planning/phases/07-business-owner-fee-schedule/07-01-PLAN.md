```php
public function approveBusinessOwner(BusinessOwner $businessOwner): void
{

}
private function activate(Partner|BusinessOwner $record, ?User $user): void
{
    $oldValues = $record->getOriginal();
    $record->forceFill(['status' => RecordStatus::Active])->save();
    if ($user && $user->status !== UserStatus::Active) {
        $user->forceFill(['status' => UserStatus::Active])->save();
    }
    app(AuditLogger::class)->log(
        actor: auth()->user(),
        event: 'approved',
        auditable: $record,
        oldValues: $oldValues,
        newValues: $record->fresh()->getAttributes(),
    );
}
```

       ```php
       public static function activeAmount(FeeType $type, ?\Illuminate\Support\Carbon $on = null): ?string

           $on = $on ?? now();
           return static::query()
               ->where('fee_type', $type)
               ->where('status', RecordStatus::Active)
               ->where(fn ($q) => $q->whereNull('effective_from')->orWhere('effective_from', '<=', $on->toDateString()))
       ```

       ```php
       public function approveBusinessOwner(BusinessOwner $businessOwner): void
       {
           $this->activate($businessOwner, $businessOwner->user);
           $this->generateSetupFee($businessOwner);
       }

       private function generateSetupFee(BusinessOwner $businessOwner): void
       {
           $amount = FeeSetting::activeAmount(FeeType::BusinessOwnerSetup) ?? 10.00;

           $fee = Fee::firstOrCreate(
               [
                   'business_owner_id' => $businessOwner->id,
                   'fee_type' => FeeType::BusinessOwnerSetup,
                   'billing_period' => null,
               ],
               [
                   'partner_id' => $businessOwner->partner_id,
                   'amount' => $amount,
                   'due_date' => now()->addDays(30)->toDateString(),
                   'status' => FeeStatus::Unpaid,
               ],
           );

           if ($fee->wasRecentlyCreated) {
               app(AuditLogger::class)->log(
                   actor: auth()->user() ?? User::system(),
                   event: 'fee_generated',
                   auditable: $fee,
                   newValues: $fee->getAttributes(),
               );
           }
       }
       ```
    2. Add imports: App\Models\Fee, App\Models\FeeSetting, App\Enums\FeeType, App\Enums\FeeStatus. (User, BusinessOwner, AuditLogger already used.)

Because billing_period is NULL, MySQL's unique index does NOT enforce it — firstOrCreate's SELECT-then-INSERT IS the guard here. The `where('billing_period', null)` lookup correctly matches the existing NULL row, so re-approval finds the existing fee. Audit only fires on wasRecentlyCreated so re-approval does not duplicate the audit entry either.
