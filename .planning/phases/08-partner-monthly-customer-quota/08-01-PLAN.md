Partner model (app/Models/Partner.php):
  - $partner->id
  - $partner->customers(): HasMany  (hasMany Customer via partner_id)
  - Convention: domain constants live as class consts (e.g. Partner::MAX_DIRECT_PARTNERS = 4).

App timezone: config('app.timezone') === 'Asia/Kuala_Lumpur' (set in Phase 6, env-driven).
  Because the app default timezone is now Asia/Kuala_Lumpur, Carbon now() and ->startOfMonth()
  already resolve in MYT. Compute the half-open range with Carbon (CarbonImmutable) explicitly
  anchored to the Asia/Kuala_Lumpur timezone so the boundary is correct even if APP_TIMEZONE is
  overridden in some environment.

Half-open range rule (from PITFALLS.md Pitfall 8):
  $start = CarbonImmutable::parse($reference, 'Asia/Kuala_Lumpur')->startOfMonth();
  $nextStart = $start->addMonth();
  ...->where('created_at', '>=', $start)->where('created_at', '<', $nextStart)
  Use a half-open interval [start, nextStart). Do NOT use whereMonth/whereYear (timezone trap)
  and do NOT use whereBetween($start, $end->endOfMonth()) (the 23:59:59 boundary gap).

Single canonical column (from PITFALLS.md Pitfall 9):
  Count customers.partner_id directly. Do NOT also join/aggregate business_owner sub-counts
  (avoids double counting). partner_id is the one canonical attribution column.
