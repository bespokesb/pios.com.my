<!-- The EXACT gating pattern to copy lives in CustomerForm. -->

CustomerForm gates business-owner-only fields with a Closure returning a bool (app/Filament/Resources/Customers/Schemas/CustomerForm.php):
```php
private static function visibleToNonBusinessOwner(): Closure
{
    return fn (): bool => ! (auth()->user()?->isBusinessOwner() ?? false);
}
// usage on a Section or field:
->visible(self::visibleToNonBusinessOwner())
```
For Vendor sourcing the gate is the INVERSE — admin ONLY (stricter than "not business owner", because partners must ALSO be excluded):
```php
->visible(fn (): bool => (bool) (auth()->user()?->isAdmin() ?? false))
```
auth()->user()->isAdmin() (App\Models\User) returns true only for admin/system-managing roles (SysAdmin / PiosOwner), false for Partner and BusinessOwner.

CRITICAL: ->visible(false) in Filament removes the field from the schema AND prevents dehydration, so a non-admin cannot submit cost/vendor. This is the column-level guarantee. Do NOT rely on ->hidden() CSS or ->disabled() alone.

ProductForm (app/Filament/Resources/Products/Schemas/ProductForm.php) current structure: Sections 'Generated IDs', 'Classification', 'Product Details', 'Pricing' (has selling_price + sales_commission TextInputs, prefix 'RM'), 'Media and Promotion'. selling_price is the customer/selling price. Select is already imported.

ProductsTable (app/Filament/Resources/Products/Tables/ProductsTable.php) current columns include selling_price (->money()->sortable()). TextColumn is already imported. Add cost + vendor + margin columns here, admin-gated.

ProductResource is SHARED: AdminPanelProvider discovers it; BusinessPanelProvider explicitly registers ProductResource::class in ->resources([...]). So the SAME form/table classes render in both panels — gating MUST be inside ProductForm/ProductsTable, not in a panel config.

Computed margin column (non-DB), null-safe:
```php
TextColumn::make('margin')
    ->label(__('pios.product.margin'))
    ->state(fn (\App\Models\Product $record): ?string => $record->cost === null
        ? null
        : 'RM '.number_format((float) $record->selling_price - (float) $record->cost, 2))
    ->visible(fn (): bool => auth()->user()?->isAdmin() ?? false)
```

Test conventions (tests/Feature/ProductCatalogTest.php + FilamentAccessTest.php):
- Use RefreshDatabase; User::factory()->create(['role'=>UserRole::SysAdmin|Partner|BusinessOwner, 'status'=>UserStatus::Active]).
- A BusinessOwner user needs a BusinessOwner record (mirror ProductCatalogTest::businessOwnerUser) so ProductResource::getEloquentQuery / panel access behaves.
- Filament Livewire form-field assertions: Livewire::test(CreateProduct::class)->assertFormFieldExists('cost') / ->assertFormFieldDoesNotExist('cost'). These are the AUTHORITATIVE column-level checks. Acting as admin: assertFormFieldExists('cost') and assertFormFieldExists('vendor_id'). Acting as BO and as Partner: assertFormFieldDoesNotExist('cost') and assertFormFieldDoesNotExist('vendor_id').
- "BO cannot set cost" proof: acting as BO, Livewire::test(CreateProduct::class)->fillForm([...without cost...])->call('create') — then assert the created product's cost is null. (The field being absent means a submitted cost would be ignored; assertFormFieldDoesNotExist already proves absence.)
- Table isolation: create a product with a known cost via DB (Product::create([... 'cost' => 40, 'selling_price' => 100 ...])). Acting as BO: Livewire::test(ListProducts::class)->assertDontSee('RM 60.00')->assertDontSee('40.00') (margin/cost values absent). Acting as admin: ->assertSee('60.00') (margin present). Note: only active products are visible to BO via scopeVisibleTo — make the product status Active.
- Vendor policy denial: assertTrue(Gate::forUser($businessOwnerUser)->denies('viewAny', \App\Models\Vendor::class)); assertTrue(Gate::forUser($partnerUser)->denies('viewAny', Vendor::class)); assertTrue(Gate::forUser($admin)->allows('viewAny', Vendor::class)).
- Vendor route isolation: $routes = collect(\Route::getRoutes())->map(fn ($r) => $r->uri())->all(); assertContains('admin/vendors', $routes); assertNotContains('business/vendors', $routes); assertNotContains('partner/vendors', $routes).
