<objective>
Stand up the BO-owned CRM data foundation — two separate, strictly-scoped tables (`customer_notes`, `customer_follow_ups`) with their own `scopeVisibleTo` + registered policy + denormalized `business_owner_id` — plus the stateless `App\Support\Phone` helper, so every later CRM screen (Phases 11–16) inherits a leak-proof ownership boundary instead of inventing one.

Purpose: This is the highest-risk slice of milestone v1.2. The ownership invariant (a BO only ever sees their own customers' notes/follow-ups) must be enforced server-side in the model scope + policy BEFORE any UI consumes it. Once UI exists, a missing child scope leaks PII through a direct query (a reminder widget, a report) with no parent gate to catch it.
Output: 2 NEW migrations, `CustomerNote` + `CustomerFollowUp` models, 2 policies registered in `AppServiceProvider`, `Customer` notes()/followUps() relations, `App\Support\Phone`, and tests proving ownership isolation + overdue computation + phone normalization with no regressions.

Out of scope (Phases 11–16): ANY Filament Resource/RelationManager/ViewPage/Action/form/widget, the customer detail view, segments, WhatsApp UI. This plan adds NO forms — `business_owner_id` is never set via form input here; it is stamped server-side in tests by passing it directly to create().

public function scopeVisibleTo(Builder $query, User $user): Builder
{
    if ($user->isAdmin()) {
        return $query;
    }
    if ($user->isPartner() && $user->partner) {
        return $query->where('partner_id', $user->partner->id);

    ```php
    namespace App\Support;

    class Phone
    {
        /** Strip everything except digits; '' for blank/null. */
        public static function digits(?string $raw): string
        {
            if ($raw === null || trim($raw) === '') {
                return '';
            }
            return preg_replace('/\D+/', '', $raw) ?? '';
        }

        /** Normalize a MY mobile to intl wa.me digits (e.g. 60123456789); null if blank. */
        public static function toWhatsApp(?string $raw, string $cc = '60'): ?string
        {
            $d = self::digits($raw);
            if ($d === '') {
                return null;
            }
            if (str_starts_with($d, '0')) {
                $d = $cc.substr($d, 1);           // 012… → 6012…
            } elseif (! str_starts_with($d, $cc)) {
                $d = $cc.$d;                       // bare 1x… → 601x…
            }
            return $d;                            // already 60… kept
        }

        /** E.164-ish tel: form (+60123456789); null if blank. */
        public static function toTel(?string $raw): ?string
        {
            $d = self::toWhatsApp($raw);
            return $d ? '+'.$d : null;
        }
    }
    ```
