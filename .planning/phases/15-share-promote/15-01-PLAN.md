<objective>
Add PLST-04: a one-tap "Share" record Action on the Business Owner product listing that opens a pre-filled WhatsApp message (`https://wa.me/?text=` + rawurlencoded text) containing the product name, `RM <selling_price>`, description, and optionally a public image URL — offered ONLY on the BO's own products and built so it can NEVER leak cost/vendor/margin.

Purpose: This is the lightweight, text-only promote action that makes the seller catalog useful. The message builder is a pure method on `Product` (testable in isolation, structurally incapable of emitting cost/vendor), the gating is a `ProductPolicy::share` ability (server-side own-check), and the default template is bilingual. No public landing page / unauthenticated route is built — that surface (SHARE-PUB-01) is deliberately deferred to v2 because a guest route bypasses the `visibleTo` scope and exposes cost/margin/cross-BO catalog (PITFALLS.md Pitfall 4).
Output: `Product` share-message methods, `ProductPolicy::share`, the Share Action wired into `ProductsTable`, bilingual `product.share.*` lang keys, and a Feature test proving the URL contents, the cost-omission, and the own-products-only gating. Full suite stays green.

Out of scope: any `routes/web.php` entry, controller, Blade view, signed URL, or public product page (SHARE-PUB-01 / v2); sharing to a specific customer's number (the generic `wa.me/?text=` picker is the v1.2 shape — no recipient, so no `App\Support\Phone` dependency); any change to product create/edit forms or the card grid (those are Phase 14).
</objective>

    ```php
    public function shareMessage(): string
    {
        $lines = [
            __('pios.product.share.intro'),
            $this->name,
            __('pios.product.share.price', ['price' => number_format((float) $this->selling_price, 2)]),
        ];

        if (filled($this->description)) {
            $lines[] = '';
            $lines[] = $this->description;
        }

        if ($imageUrl = $this->firstShareableImageUrl()) {
            $lines[] = '';
            $lines[] = $imageUrl;
        }

        return implode("\n", $lines);
    }

    public function shareWhatsAppUrl(): string
    {
        return 'https://wa.me/?text='.rawurlencode($this->shareMessage());
    }

    public function firstShareableImageUrl(): ?string
    {
        foreach ($this->media_assets ?? [] as $asset) {
            if (is_string($asset) && preg_match('/\.(jpe?g|png|webp|gif)$/i', $asset)) {
                return Storage::disk('public')->url($asset);
            }
        }

        return null;
    }
    ```
